# **Looping Statement**
# Types=
## **For loop :** 
### when we know the count of iterations or repeations.
### Syntax:
#### declaration of variable
#### for(initialization;condition;incre/decre){
#### //block of code to execute   
#### }

### **While loop :**
### When we dont know counts of iterations but know the condition.
### Syntax:
#### Initilization
#### While(condition){
#### //block of code to execute  
#### increment/decrement 
#### }
