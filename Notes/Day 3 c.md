# Variable in C
## Variable is name of simple memory location 
## We should follow some rules to define variable names
| | | |
| :--- | :--- | :--- |
|   | Name |  |
| Address  | data | Size |
|    | type |  |

## Rules
* **Only alphabets,numbers,special characters** 
* **We have to starts from only alphabtes and special character, not from digit**
* **Digit can be used in middle or at last**
* **We cant use here blank space / void space**
* **We cant use any keyword as variable names**
### examples
| Valid | Invalid |
| :--- | :--- |
| int abc=30; | int 9abc=30; |
| int ab3c=20; | int ab c=20; |
| int ab_c=20; | int long=30; |

## Variables Types:- 
* ## Basic
* **int,char,float,double**
* ## Derived
* **Array, structure, union, printer**
