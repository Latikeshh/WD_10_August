# **Call by value**
* **In call by value when we call the function by value it means that we are passing the value of the arguments. Which are copied into the formal parameters of the function that means that original value remain same and the formal parameter inside function will change**
---
### **Formal Parameter**
* **Are local variables which are assigned values from the actual parameters or arguments when function is called**
---
### **Actual Parameter**
* **When a function is called the values that are passed in the call are called the arguments or actual parameter**
---
