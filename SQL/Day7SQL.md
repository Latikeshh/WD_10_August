# 🔑 SQL Keys

### A **key** is used to identify records and create relationships between tables.

## 📌 USE

- Key is used to combine 2 or more columns.
- Key is used to **identify records**.
- It is used to **create relationships between 2 or more tables**.
- It helps maintain **unique and valid data**.

---

## 🔑 Types of Keys

- **Primary Key** → Uniquely identifies each row.
                     One Table = One Primary Key.
- **Foreign Key** → Creates a relationship between two tables.
- **Composite Key** → Uses to combine **2 or more columns together** to uniquely identify a row.
                    Column combinations
- **Candidate Key** → A column that **can become a Primary Key**.
- **Alternative Key** → A Candidate Key that is **not selected as the Primary Key**.  
- **Unique Key** → Ensures that values in a column are **not duplicated**. unique but also null
                    One table = no of unique key.
